# 🚀 Smart Local Help & Emergency Assistance App

## 🧠 Problem Statement
In many areas—especially smaller cities—people often struggle to:
- Find trusted local service providers (electricians, plumbers, mechanics)
- Get immediate help during emergencies (accidents, health issues)
- Share their live location quickly in unsafe situations

There is no single, simple platform that combines all these essential services.

---

## 💡 Solution
**SmartHelpApp** is an Android application designed to:
- Connect users with nearby service providers
- Provide a one-tap emergency SOS system
- Share live location instantly with trusted contacts
- Work even with limited or no internet connectivity

---

## 🎯 Key Features

### 👤 1. User Module
- User Signup / Login (Firebase Authentication)
- User Profile Management
- Add & Manage Emergency Contacts

---

### 🆘 2. Emergency SOS Button (Core Feature)
- One-tap SOS alert
- Sends:
  - 📍 Live Location (Google Maps API)
  - 🚨 Emergency message to saved contacts
- Optional:
  - 📞 Auto-call to emergency contact

---

### 📍 3. Nearby Help Finder
Find nearby:
- ⚡ Electricians  
- 🚰 Plumbers  
- 🔧 Mechanics  
- 🏥 Medical Help  

Features:
- Google Maps integration
- Distance-based results
- Direct call/contact option

---

### 📡 4. Live Location Sharing
- Share real-time location with selected contacts
- Useful for:
  - Night travel safety
  - Tracking during emergencies

---

### 🌐 5. Offline Mode (Advanced)
- Stores emergency contacts using SQLite
- Sends SMS alerts when internet is unavailable

---

### ⭐ 6. Ratings & Reviews
- Users can rate and review service providers
- Builds trust and reliability

---

### 🔔 7. Notifications
- SOS alerts
- Service updates
- Emergency notifications
